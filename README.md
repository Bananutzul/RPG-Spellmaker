# RPG-Spellmaker # POO Project 1
The project consists of a game that allows the user to create 3 spells out of 5 options (based on different elements), and fight a boss that has 10 attack instances chosen from a list of 5 possible attacks. The attacks correspond with the list of elements the player can choose from while selecting spells. The goal of the game is to defeat the boss within 10 turns using the chosen spells.
